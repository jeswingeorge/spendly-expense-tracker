### Best Practices
1. **Model Selection**: Use Opus while creating plan mode (even though it will consume a lot of tokens) but for implementation use sonnet.
2. **Extended Thinking**: Claude will take more time to think and give you answer so higher chances of accuracy. Claude does this reasoning on scratchpad. So once the reasoning is done, Claude based on the reasoning done in scratchpad starts answering. Turn this mode on while planning. 
   [Turning this mode On/Off](https://youtu.be/yz-7Oczvg34?list=PLKnIA16_RmvaYH3poI0oJvbDF4zEvpq8W&t=1616).   
    Go to Claude terminal => `/claude`  and Turn Thinking Mode => `On`. For me its On by default.

3. **Effort Level**: You have to put some restriction on thinking time with a limited tokens(which will be written on scratchpad). 
   Four types of effort levels: Low, medium, high and max.   
   `Max` will allow highest number of tokens for thinking and more time. It comes with Focus Mode. Better to keep it in Medium or High. Use command `/effort` and select mode.

4. **Ultraplan**: Superior altenrative to plan mode.  here Claude creates a container in cloud and Opus creates a plan use it only if you are using a very complex workflow.
