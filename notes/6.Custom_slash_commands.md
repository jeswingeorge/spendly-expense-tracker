# [Claude Code Custom Slash Commands | Stop Repeating Prompts](https://youtu.be/ep2P9hvmvzY?si=iJGpoZ9iYHO1EDpp)

* Saved prompts invoked with a simple `/command_name` syntax
* Used to execute any repeatable workflow in your project
* Stored as Markdown files inside the `.claude` folder
* **Two types:**
  * **Project-scoped** — stored in `.claude/commands/`, available only within that project
  * **User-scoped** — stored in `~/.claude/commands/`, available across all your projects
* **Examples:**
  * **/review** — runs a code review checklist on the current file
  * **/commit** — generates a git commit message based on staged changes
  * **/test** — runs the test suite and analyzes any failures
  * **/security-scan** — scans the codebase for common vulnerabilities like SQL injection or exposed credentials
  
## Create Custom Slash Commands

Here we will create custom slash commands to populate our database tables.  
We have 2 tables: **user** and **expense**.  We will add 1 row to user table and 4 rows to expense. This process of adding data manually during development is known as **seeding**.

1st create a folder named **commands** in the **.claude** folder. This will have all your custom commands in markdown format. The name you give to your markdown file will be the name of the slash custom commands too.

This command will have these sections:
1. **description**: This gives details on what command will do. It will show up in claude cli when you type in the /command-name. Keep it brief.
2. **allowed-tools**: What access it has? EG: Read, Write, etc. And which commands or tools it can use? Eg: Bash(python3:*)
3. Give the task to be done step-by-step along with the restrictions.

Once the file has been written, you need to restart the session for the custom commands to be rendered useful.
